# Art research (working notes)

Working notes for the pixel-art upgrade of Thrills & Chills. These files are research, not specifications. The specification will be written from `approach/recommendation.md` after the owner decides.

- `understand/` — a map of the game's drawing code (nine readers and one critic).
- `approach/` — three proposals, three reviews, the recommendation, and proof pictures of the chosen method on the real art functions.
- `intro/` — five designs of the intro screen (the owner picked E, skyline), the shared kit, and the two overview sheets.
- `drafts/pixel3.py` — the script that drew the approved draft pictures.
